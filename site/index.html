How this host works

Free tools · FedRAMP 20x

Tools that run in your browser.

Everything on this host is static files. There is no server behind it, no account, no analytics, and no way for a page here to send anything anywhere. Load a tool, disconnect from the network, and it still works.

nothing leaves your machine

  • SDR Redactor

    Redact a FedRAMP Security Decision Record for sharing. Statuses, identifiers, dates, and counts stay. Names, links, resources, accounts, and narrative text are replaced.

    Open the redactor →

The rule for this host is public and enforced by its configuration: one strict Content Security Policy on every path, one deploy role per tool, and no code in front of the files. Read the configuration.
